# 📱 Navegação entre Telas com Jetpack Compose

> **Projeto Acadêmico**

---

## 📌 Descrição

Este projeto tem como objetivo demonstrar a implementação de navegação entre múltiplas telas em um aplicativo Android utilizando Jetpack Compose.

A navegação é controlada por meio do NavController, permitindo transições entre telas e a passagem de parâmetros via rotas e query strings.

---

## 🎯 Objetivos

- Implementar navegação entre telas
- Utilizar NavController
- Trabalhar com rotas e argumentos
- Demonstrar passagem de parâmetros entre composables

---

---

## 📱 Funcionalidades

- Tela de Login  
- Tela de Menu  
- Tela de Perfil (recebe nome e idade)  
- Tela de Pedidos (recebe cliente opcional)  
- Navegação entre telas com controle de pilha (Back Stack)  

---

## 🔄 Fluxo de Navegação

Login → Menu → Perfil  
      ↓  
     Pedidos  

Retornos:
- Perfil → Menu  
- Pedidos → Menu  
- Menu → Login
